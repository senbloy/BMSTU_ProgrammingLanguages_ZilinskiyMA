[Источник задания](https://github.com/NatkinMA/BMSTU_ProgrammingLanguages_NatkinMA/tree/main/laboratory_work_01), PDF, печатная страница 13.

Вычислить две формулы:

```text
z1 = (cos(alpha)-cos(beta))² - (sin(alpha)-sin(beta))²
z2 = -4 sin²((alpha-beta)/2) cos(alpha+beta)
```

Алгоритм: ввести два конечных вещественных угла в радианах; вычислить обе формулы; вывести значения и абсолютную разность. Область определения — любые конечные углы. Отличие на последних разрядах возможно из-за округления float.

```text
python -m Laboratory_work_01.solution
```

Контрольные примеры (математические значения):

| alpha | beta | z1 = z2 |
|---|---|---|
| 0 | 0 | 0 |
| 0 | pi | 4 |
| pi/2 | -pi/2 | -4 |
| 0 | pi/2 | 0 |
| pi | pi/2 | 0 |

Число pi при вводе замените на 3.141592653589793; pi/2 — на 1.5707963267948966. Результаты запусков приведены в `examples.txt`.
