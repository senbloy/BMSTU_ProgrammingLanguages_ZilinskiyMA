# BMSTU_ProgrammingLanguages_ZilinskiyMA

Семь лабораторных по дисциплине «Языки программирования», **вариант 9**.

Задания взяты из [репозитория NatkinMA](https://github.com/NatkinMA/BMSTU_ProgrammingLanguages_NatkinMA). Решения написаны отдельно; примерные программы из исходного репозитория не используются.

| Папка | Тема | Выполненные задания |
|---|---|---|
| Laboratory_work_01 | Линейные программы | Две эквивалентные формулы |
| Laboratory_work_02 | Ветвления | Кусочная функция; принадлежность точки области |
| Laboratory_work_03 | Циклы | Таблица функции; 10 выстрелов; ряд arctg |
| Laboratory_work_04 | Одномерные массивы | Максимум по модулю; сумма; перемещение нулей |
| Laboratory_work_05 | Матрицы и функции | Сглаживание; сумма ниже диагонали |
| Laboratory_work_06 | Файлы | Файловые версии работ 1, 4 и 5 |
| Laboratory_work_07 | Графика turtle | График; Монте-Карло; график ряда |

## Запуск

Нужен Python 3.9 или новее. Внешние библиотеки для решений не нужны. Для графики нужен Tk/turtle и графический сеанс. В Astra Linux при отсутствии Tk установите `python3-tk` из репозитория ОС.

Откройте терминал в корне скачанного репозитория:

```text
python -m Laboratory_work_01.solution
python -m Laboratory_work_02.solution
python -m Laboratory_work_03.solution
python -m Laboratory_work_04.solution
python -m Laboratory_work_05.solution
python -m Laboratory_work_06.solution 1 Laboratory_work_06/input_01.txt Laboratory_work_06/output_01.txt
python -m Laboratory_work_06.solution 4 Laboratory_work_06/input_04.txt Laboratory_work_06/output_04.txt
python -m Laboratory_work_06.solution 5 Laboratory_work_06/input_05.txt Laboratory_work_06/output_05.txt
python -m Laboratory_work_07.solution 1
python -m Laboratory_work_07.solution 2 --radius 2 --count 10000 --seed 9
python -m Laboratory_work_07.solution 3
```

В Linux команда интерпретатора может называться `python3`. Десятичный разделитель — точка. Углы — в радианах. Можно также запускать `solution.py` напрямую из соответствующей папки; для работы 6 пути к файлам задаются относительно текущей папки.

Каждая папка содержит описание задания, алгоритм и примеры. `examples.txt` содержит результаты настоящих запусков консольных программ; выходные файлы работы 6 также получены запуском программы.

## Проверка

```text
python -m unittest -v test_solutions
```

Проверяются контрольные значения, границы областей, сохранение исходных массивов, точность ряда, файловые форматы и площадь по независимому численному интегрированию. Для выбора повторяемой последовательности случайных чисел в работах 3 и 7 используется seed.

## Уточнения условий

- График варианта 9 в работе 2 изображён от x=-7 до x=4. За этими границами значение не задаётся; горизонтальные оси не считаются продолжением графика.
- В записи суммы ряда arctg в PDF есть несогласованный знак `(-1)^(n+1)`. Использован правильный ряд из приведённого там же разложения: x - x³/3 + x⁵/5 - …; результат сравнивается с `math.atan`.
- Общие требования работы 5 предлагают запрашивать размеры; вариант 9 отдельно задаёт 10x10. Размер по умолчанию — 10x10, ввод размеров сохранён для проверки на малых матрицах.
- Под «максимальным по модулю» выводится сам элемент и его модуль; при равенстве модулей выбирается первый.
- Если нет двух положительных элементов, сумма между ними не определена. При соседних положительных элементах сумма равна нулю.
